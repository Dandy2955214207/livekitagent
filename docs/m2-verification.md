# M2 视频问答实现与验证

日期：2026-10-29。状态：视频链路已实现，桌面固定输入的三个视觉场景通过，摄像头控制与真实语音恢复检查通过；**手机 LiveKit 媒体通话与 20 个真实物品的人工验收待完成**，尚未宣布 M2 全部验收通过。

## 实现

- 页面先接通纯语音，用户点击开启摄像头后才申请权限与发布视频；默认后置，可切换前后镜头。拒绝摄像头权限不结束语音。
- 摄像头关闭/切换/挂断会停止本地轨道。晚到的权限结果会按通话代次丢弃并释放，避免挂断后继续采集。
- 用户 Token 仅允许发布 microphone/camera，不允许屏幕共享；Agent 仅订阅指定用户的摄像头。RoomIO 继续负责原有音频，自定义 CameraInput 负责可失效的视频流。
- RTC 视频缓冲容量 1，最新原始帧与最新编码帧各保留一份，不堆积历史图像；先采样后编码。
- 默认 1 FPS，保持比例缩放至不超过 640×480，处理视频旋转信息，JPEG 编码及 Base64 在线程中执行。JPEG 原始上限 190,000 字节，保证编码后低于供应商 256 KiB 上限。
- 同一个发送器有序发送音频/控制与最新图片；至少成功发送一次音频才允许图片。图片不主动创建回答。
- 发送前检查最大帧龄 1500 ms；关闭/切换镜头会清空待处理帧并使在途编码失效。已写入网络的帧不能撤回，关闭摄像头也不会删除模型已有的视觉记忆。
- 不录制原始音视频，不记录 Base64。日志含图像计数、替换/丢弃、接收/编码/发送单调时间、编码耗时与帧龄。帧龄从电脑收到解码帧算起，不包括手机采集与上行耗时，也不证明模型一定采用该帧。

## 已执行验证

31 项 Python 回归通过，覆盖房间/凭据边界、协议事件、输出隔离、视频 JPEG/旋转、最新帧替换、过期帧、编码失效、编码期间音频推进、首音频前禁止图片、目标摄像头过滤及关闭清理。前端生产构建通过。

隔离桌面 Edge 使用 Canvas 测试视频和固定中文合成音频，真实经过浏览器 WebRTC → LiveKit → Agent → Qwen，不使用电脑物理摄像头/麦克风。

| 场景 | 实际结果 |
| --- | --- |
| 公开狗图片 | “画面里的动物是一只狗，看起来像萨摩耶。” |
| 红色圆形、白色背景 | “红色和白色” |
| 换成蓝色后立即播放问题，不等待图像状态 | “蓝色” |
| 图像持续输入但不说话 | 没有主动回答 |
| 摄像头权限拒绝 | 同一语音会话仍可用 |
| 切换摄像头 | 旧本地视频轨道结束，仅一个新视频轨道存活 |
| 关闭摄像头后问话 | “语音仍然正常”，新增接收音频 16,864 字节 |
| 挂断时摄像头权限尚在等待 | 晚到轨道立即停止，未遗留活跃采集 |
| 390px 页面 | 没有横向溢出 |

视觉记录：`.runtime/m2-results/smoke-report-vision-pass-phrase-mismatch.json`。该记录的前三个视觉样例均通过，整体 failed 是第四个语音样例要求逐字复述，而模型回答“好的，没问题。”；不把这一结果伪装成整套脚本通过。

控制补测记录：`.runtime/m2-results/controls-report.json`，passed，零页面异常，语音接收包丢失为 0。视频累计发送约 201 KB，属于短时桌面测试，不构成移动网络性能基线。镜头切换使用模拟源验证生命周期，不能代替手机真实前后镜头切换。

挂断清理记录：`.runtime/m2-results/cleanup-report.json`，房间、活动Worker任务、API活动会话均为0。

早先失败均保留：一次执行环境网络权限阻止模型连接；一次云端 `data_inspection_failed`；一次没有具体 code 的云端 `provider_error`。相同固定输入后来完成三个视觉场景，原因未确认，不能据此承诺错误不会再出现。连接出错会结束当前会话，重新加入会重置上下文；没有自动重放或无限重试。

现在 `qwen_error` 日志会保留脱敏错误类型/消息辅助定位，页面专门解释内容检查失败。官方错误码说明：https://help.aliyun.com/en/model-studio/error-code 。

## 手机验收

用户确认 Mate 80 Pro Max 的 HTTPS 无警告、前后摄像头预览/切换、麦克风授权、实际提示音均通过。侧边排查后，当前配置为电脑 `172.20.10.9`、手机 `172.20.10.8`；沿用已有 CA，不重新安装证书。用户仅拍摄非保密测试物品，允许对应音视频发送 Qwen。

能力检测页无需 LiveKit 媒体端口；正式通话需要 TCP 7881 / UDP 7882。当前工具进程创建媒体防火墙规则被 Windows 拒绝访问，需用户在管理员 PowerShell 执行：

```powershell
& 'C:\Users\lzh\Project\LiveKitAgent\scripts\mobile-firewall.ps1' -Media
```

规则只允许配置中的手机 IP 访问配置中的电脑 IP 的指定端口。证书/HTTPS规则继续沿用。不关闭防火墙。

```powershell
# 若能力检测还在运行，先停止；不要同时占用 8443/8088
.\scripts\stop-device-check.ps1
npm.cmd run build --prefix web
.\scripts\start-mobile.ps1
```

手机打开 `https://172.20.10.9:8443/`，注意这是通话首页。先加入测试语音，再开启摄像头，等待“图像已送达 Qwen 连接”后提问。该提示表示 WebSocket 写入完成，不是模型视觉理解的确认。

建议依次测：杯子是什么 → 换成另一物品立即问 → 切换镜头 → 关闭摄像头继续语音 → 重新开启 → 挂断。第一次使用耳机。

20 个清晰真实物品可选：杯子、水瓶、勺子、碗、盘子、纸巾、无标记纸盒、铅笔、尺子、橡皮、剪刀、钥匙、鼠标、键盘、空白笔记本、苹果、香蕉、玩具车、积木、无文字遥控器。记录实际问题、正确物品/颜色、回答是否正确，以及换物后是否沿用旧画面；不需要保存或上传原始视频。每个实际样例独立计分，目标至少 18/20；当前不宣称已达标。

测试结束执行 `.\scripts\stop-local.ps1`。需要撤销测试规则时，由管理员执行 `.\scripts\mobile-firewall.ps1 -Remove`。IP变化需重新准备配置/证书及对应规则。

## 接口依据

按锁定的 LiveKit SDK 源码实现 RTC 订阅和容量限制。Qwen 要求图片前先有音频、VAD 当前轮图片在语音结束前送达、建议 1 FPS，见：https://www.alibabacloud.com/help/en/model-studio/realtime 。因此仍需手机真实换物验收，不能用发送日志代替视觉正确性。
