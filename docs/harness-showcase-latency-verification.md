# 连续介绍等待时间优化（2026-11-02）

**状态：已实现一版可回退的优化，完整交互测试通过，但 1–3 秒首音目标尚未稳定达成。** 最终原图模拟样本为 8159 / 4543 / 4564 ms（杯子/钥匙/书），中位数 4564 ms，样本量仅 3。不能把离线验证或局部最快值当成整体达标。

本轮独立保存在 `codex/showcase-latency` 分支；原稳定分支 `codex/showcase-prototype` 保持在 `03771c2`，方便比较或回退。

## 本轮保留的修改

- 停留约 0.3 秒即开始安静观察，识别与后续停留等待重叠；定时粒度降至 0.1 秒，新视频采样也可唤醒调度。
- 首次明确的新物品可返回简短身份和外观要点，不必先生成完整讲稿；由语音阶段组织介绍，实际完整播放的文本才进入已讲内容。
- 快速路径需要模型显式 `needs_confirmation=false`、未经协议纠错的新物品、至少 1.2 秒停留、不同且更新的帧、本地画面一致性检查以及相同的候选/请求上下文。补充细节、未给明确标志、不匹配或不确定时仍走模型确认。
- 若模型判断期间已经收到合格的新帧，立即使用它完成本地核对，不再额外等一个采样周期。区分“尚未核对”与“已经核对但不匹配”，避免过早退回慢路径。
- 快速候选的工具回填最多暂缓 2 秒：本地检查通过后才回填带 `speech_intent` 的讲解授权，再请求 SPEAK；超时、暂停、取消时关闭调用，或退回完整确认，不遗留未闭合工具。
- 去掉独立确认前的固定 1 秒；已讲完且画面未变化时保持低频复查。画面内容变化可以提前唤醒，但保留 2 秒冷却和既有每分钟生成预算。首次短暂 `wait` 最多两次较快复查，之后退避。
- 在新语音首音前再次检查场景、停留、新鲜度与画面一致性，并暂存早到的文字。若尚未出声就换物/移动，取消输出并保留草稿，改用新图完整确认；已出声的短段允许正常讲完。
- 仅在活动 showcase 的语音尚未开始时，对错误返回工具或失败输出允许一次纠错，所有错误工具均不执行。已开始的语音不会自动重播；普通问答和指导维持原有拒绝行为。
- 针对真实停止，最近几帧已停止时不再等整个 2 秒运动历史过期；增加有界斜向晃动测试，避免自然晃动反复清空候选。

首次配置、固定工具集合、单连接有序执行、图片提交回执、用户输入优先级、任务版本、只按播放完成记忆以及普通指导的用户确认规则均继续保留。没有改用第二个模型或新的语音服务。

## 测量与结果

`web/tests/showcase-smoke.mjs` 新增浏览器远端音轨 Web Audio 检测：从模拟新物品画面展示，到首次解码的非静音语音；此前语音尾部留出短暂排空时间。检测使用静音输出，不接触物理摄像头、麦克风或扬声器。该指标不等于真实手机听感，也不等于整段播放完成时间。

同一组带 ±48 px/±30 px 晃动、±4° 转动、±6% 缩放和明暗变化的绘制物品，用一次固定合成请求启动，检查连续介绍、扫动安静、静止不重复、暂停/继续/结束及结束后普通问答。

- 本轮开始时的基线实测为 13.5 / 26.6 / 24.6 秒，包含 `wait` 和低频复查；这不是用户报告的 4–7 秒的复现，也不是正常延迟的总体估计。
- 开发中出现过 3.4–4.1 秒的局部样本，同时有后续物品未正常出声、候选过早回退、工具/语音阶段切换、首音前取消后的恢复等失败。失败记录全部保留，不能只挑最快值报告成功。
- 恢复完整语音路由/任务上下文后，多次完整交互通过。精简首次识别内容也通过，但未稳定达到 1–3 秒。
- 384 像素首次识别图实验完整通过，但计时约 4.1–4.8 秒，没有显示可靠提速，因此已撤除该实验，最终仍上传原尺寸图片。
- 最终原图版本完整通过：三件连续介绍、去重、暂停继续结束、结束后问答、无内部控制泄漏、无多余用户消息、无页面异常。最终单轮的首音为 **8.159 / 4.543 / 4.564 秒**，详见 [完整结构化记录](harness-showcase-latency-results.json)。
- Python **122 项通过**，前端构建通过（保留既有大包提示）；清理状态见结构化记录。

这些测试跨越了电脑网络变化，不能当成严格控制网络条件的 A/B 统计，也不能据此承诺手机必然提速。当前模型识别、工具回填及语音生成仍会叠加延迟，不确定情况还会退回完整确认。

## 网络与手机复测

测试过程中电脑 IPv4 从原手机配置地址变为另一地址，原 HTTPS 入口无法绑定；用户的网络选择仍待确认。手机证书、私钥、profile 和防火墙没有因此重写。后续本地 RTC 测试仅在忽略目录的临时启动包装器中显式绑定当时网卡地址，未将这些临时参数写入正式启动脚本。

用户需先确认恢复原网络或更新手机入口，再进行真实持机体验。本轮没有用模拟测试冒充该验收。

## 保守模式与回退

`SHOWCASE_FAST_PATH=false` 可关闭快速路径，继续使用独立模型确认；可另设 `SHOWCASE_EARLY_OBSERVE_SECONDS=1.5` 恢复较晚的观察起点。`SHOWCASE_FAST_DWELL_SECONDS` 默认 1.2，`SHOWCASE_FAST_MATCH_THRESHOLD` 默认 0.12，均为工程初值。

上述开关可用进程环境配置，不需要覆盖 `.env`。本轮整体作为单独 Git 提交；若体验恶化，可回退该提交，上一版基线为 `03771c2`。未因追求数字而播放没有通过判断的自然语言、提前标记“已讲过”，或在判断不明时强行开口。
