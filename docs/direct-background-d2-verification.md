# D2 前置实现与独立本地记忆

日期：2026-11-02（Asia/Shanghai）。状态：本地任务/记忆管理及独立 Monitor 组件已实现，离线验证通过；**D2 主动提醒及 D4 模型记忆闭环未验收**。

## 行为与入口

继续使用 `scripts/run_local.py --direct-background`；已有手机 profile 可加 `--mobile`。前台仍由 M2 的 RealtimeSession、供应商语义 VAD 和原音频链路直接回答，普通轮次没有 DECIDE/SPEAK、本地 VAD 或强制工具调用。H2 继续由原 `--harness` 显式启动。此次未启动/停止现有手机服务，也未改变 `.env`、提供商或默认模式。

新模式通话接通后显示“观察与本地记忆”面板。观察目标可登记、修改和取消，当前明确登记为暂停；没有启动 Monitor，也不会口头承诺正在提醒。恢复操作在服务端拒绝，前台普通提问继续回答。自然语音任务工具尚未开放，不通过转写关键词创建任务。

本地记忆可手动保存事实、选择已有事实进行纠正、删除、禁用、清空及检索。匿名通话默认 SQLite 内存库隔离；显式输入库 ID 并点击“选择库”后才使用 `.runtime/memory/<library_id>/records.sqlite3`。重新选择同一库可恢复手动保存的文本事实，不自动恢复观察任务、旧事件或旧媒体。切换库不隐式开启已禁用的记忆。

记忆界面始终显示“尚未回注模型”。数据没有发送到模型上下文，不能据此宣称模型记住、已从云端删除或跨连接对话恢复。禁用后停止收集本地近期文本、排除检索并清空本通话近期缓冲，不删除持久事实；启用可重新读取。清空/删除只影响选中的本地库，不执行任何远端删除。

## 实现

- `observation/tasks.py` 管理一个活动任务、revision、call/Monitor/camera epoch、五秒帧龄、任务有效期及重复抑制。once 事件接受后监控 completed，唯一队列事件仍可投递；取消、修改或镜头失效会撤销旧队列。重复任务需要 negative 后重新进入，unknown 或冷却到期不能自行重播。事件队列最多四项并合并当前任务旧报告。没有用物体名称或像素稳定规则完成语义识别。
- `observation/monitor.py` 提供独立文本 Qwen 客户端适配与注入式调度器，不持有音频播放权限。只使用同一 Settings 的模型和提供商，不读取真实麦克风；分块协议静音及已有编码图像由独立连接提交。模型只返回小 schema，程序绑定来源 ID。禁止输出音频、工具、意外自动生成及真实转写；空转写完成回执可区分处理，未知内容拒绝接受。
- Monitor 最多一个当前推理和一个最新待处理片段，重复 frame ID 跳过，最多两帧，十秒请求超时；默认每分钟最多二十次尝试、每个 runner 生命周期最多十次尝试，无内部纠正重试。预算不足丢弃片段不堆积；三次失败暂停，HTTP 401/403/429 立即暂停。预算按尝试计数，超时不会退还额度。运行时尚未装配此付费组件，须通过 P0 并完成源关联/调度后再启用。
- `memory/store.py` 使用本地 SQLite 事务保存文本和来源；当前事实最多十六条，其他历史最多三十二条，总计最多四十八条，每条内容最多一千字符。纠正原子标记旧事实 superseded，删除纠正不会使旧事实复活。只读 lexical 检索排除 superseded/过期记录，最多八项及三千字符，明确标记历史观察及引用数据。无向量库、额外模型、embedding 或摘要调用。
- `coordination/direct.py` 管理严格 UI 命令、最近三十二个幂等请求及八个等待操作。数据库操作在线程中执行；普通音频发送/模型生成不等待数据库。已有用户转写和生成文字只进入本通话有界内存，不自动抽取事实或持久化个人对话。生成文字标为 generated_unconfirmed，没有写入“已播放”记忆。
- Worker 只接受目标参与者的可靠 `agent.direct.control` 包，入站最多 8192 字节，调度工作也有上限。返回记录预览并限制查询响应大小，不把所有原始记录无限塞入 RTC 包。挂断时关闭本地库，清除任务/事件/近期文本。页面使用 textContent 展示记忆，支持确认等待与离开时清理。

## 验证及限制

170 项 Python 回归通过；前端生产构建通过，保留原有 >500kB 包大小提示。新增覆盖任务幂等、一次提醒完成与投递区分、negative/unknown 重入、旧版本/镜头/帧龄/乱序结果拒绝、慢推理只保留最新片段、超时/分钟及通话预算、隔离文本适配器、事实纠正事务、跨库隔离/显式恢复、禁用/清空/记录上限、消息大小，以及“本地任务/事实不阻塞前台直接回答”。云端适配器使用 fake client 验证，不作为提供商兼容证据。

`node web/tests/direct-local.mjs` 离线页面检查通过：确认前按钮禁用、暂停目标登记、纠正使用真实 record_id、HTML 文本无执行、390px 无横向溢出、离开清理。网页由 Playwright 在本地请求拦截器内提供，不启动服务、不连接 RTC/模型、不申请物理设备。报告和截图：`.runtime/direct-background-ui/report.json`、`phone-local.png`。首次 UI 测试使用 about:blank 导致 crypto.randomUUID 无安全上下文而失败；随后改为拦截的 localhost 页面，测试通过，未改变产品端的媒体或安全设置。

本轮追加真实探针在进程创建前被自动审批拒绝，理由是此前明确批准的单次付费验证已经执行，追加调用需要明确授权；没有发送新媒体、绕过审批或更换目的地。**本轮新增模型生成 0，新增模型用量 0**。此前一次 194 reported tokens 的失败及未知前台输入费用仍保留在 D0 报告，不改写为成功。

待验：P0-A/B/C 的双连接完整回答、红蓝切换和转写内容；P0-D/E 事件注入、自动轮次竞争、源关联及真实 server_playout；P0-F 任务工具；P0-G 模型实际使用纠正与恢复；P0-H 实际账户价格和完整用量；手机提醒/插话/外放回声及二十分钟稳定性。没有完成 RTC 端到端验收，不报告性能分位数或主动提醒成功率。
