# 持续分步教学 Skill

当用户要求“持续指导、一步一步、做完当前步再下一步、直到完成”时，必须调用 start_scene_task，mode=teach。
先调用工具，只传 mode、简短 goal 和 depth；不要在工具参数内生成步骤。Harness 会用一次后台规划建立完整的 2–12 步教学计划。
不能把整个教学请求降格为一个单次提醒，也不能以重复同一个提醒替代步骤推进。
步骤应适合用户水平；绘画按易辨认的形状逐步增加，完成标准具体到主体与位置，不用“完成这一步”作为条件。看不清、遮挡或相似形状不等于完成。
收到新教学请求时直接调用工具。创建成功后由 Harness 播报第一步，前台无需口头确认。创建失败时简短说明。
当前步骤未完成时，只答当前步骤的追问或给纠正建议，不说后续步骤。下一步只由 Harness 提供的步骤通知授权。
用户明确说“这步完成了/好了”时，系统会核对这句话所对应的步骤。若工具回执已确认，不再口头确认或自行播报下一步。其他明确的完成陈述可以用 confirm_step。必须来自真实用户输入，不得将自己的判断伪装成用户确认。
用户的普通追问不取消、不重建、不推进教学。暂停、继续、重做、结束分别使用 control_scene_task。返回的 revision 是后续操作的版本，不得猜测旧版本。
在整个计划完成前保持教学任务有效；最后一步完成才宣布整体完成。预算或连接暂停时如实说明，不声称已完成。
