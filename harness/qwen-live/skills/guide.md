# 画面主体讲解 Skill

当用户希望持续介绍展品、植物、物品时，调用 start_scene_task，mode=guide，goal 简短保留用户限定的主体和关注点，depth 根据用户要求选 brief/normal/deep。
先分别判断持续性、对象范围和内容深度，不按“讲解/分析/介绍”某个词选择工具。“讲解一下/分析一下当前物品”默认是一次性问答，直接基于当前画面回答；“持续分析我接下来展示的物品”也属于 guide。仅在用户明确持续跟随或上下文已建立持续任务时使用持续模式。一次性问答同样尊重用户指定对象，不自动枚举背景；用户明确要求全部物品时才分析全景。
不要用单次提醒或无范围的连续环境解说替代讲解任务。一次性“这是什么”可以直接回答。
收到持续讲解请求时直接创建任务。创建成功后等待首次观察，由任务播报第一段讲解，前台不重复确认启动。创建失败时简短说明原因。同一轮若还有其他请求，只回答其实际结果。
只围绕当前重点主体讲解，背景仅在解释主体所必需时提及。展签/植物名牌优先于外观猜测；身份不能确定时明确不确定，不编造年代、作者、种名。
深度与播报长度分开：brief 一个重点，normal 两个重点，deep 最多四个短段；每段一至两句。用户可随时追问、调整关注点/深度。
收到讲解观察事件时，只讲本次 summary，不补充背景，不回顾上一主体。主体切换后旧内容失效。
当前主体由 target 标识和区域锁定。镜头转动、靠近拍细节不等于更换物品；当前主体讲完后可以安静等待，不主动找边角/背景物品补讲。展签只能辅助解释对应的主体。
用户纠正“左边那件/不是这个，是后面的花”时，使用 control_scene_task(action=target,targetHint=用户指定对象)，保留 focus 和讲解深度。不要直接声称已经切换成功，等待新画面确认。手机点选只纠正一次当前主体，确认后按普通规则跟随展示。目标不明确时用一句话询问，不枚举全景。
用户提问直接回答，随后保留讲解任务；只有用户要求停止/暂停/修改时才使用 control_scene_task。
